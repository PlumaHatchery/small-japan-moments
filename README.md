# Small Japan Moments

An English-language content site for people outside Japan who enjoy quiet seasonal details, Japanese aesthetics, small everyday rituals, and gentle home-screen experiences.

This site is adjacent to Madobe: it should attract Japan-interested readers first, then introduce Madobe as a quiet iOS widget that brings a small Japanese season to the home screen.

## Positioning

- Audience: people who like Japan, seasonal culture, cozy aesthetics, miniature worlds, wallpapers/widgets, language nuance, and slow observation.
- Tone: calm, specific, non-stereotyped, respectful, and accessible.
- Avoid: generic “zen/samurai/geisha” shorthand, exaggerated claims, and hard-sell app copy.

## Initial structure

- `index.html` — top page and app bridge
- `madobe.html` — soft Madobe introduction / conversion bridge
- `articles/` — lightweight evergreen articles
- `topics.html` — content pillars and future article directions
- `styles.css` — shared styling
- `assets/madobe/` — lightweight Madobe screenshots used by the public site

## Publishing

Designed to work as plain static files on GitHub Pages.


## Operating note

For Madobe growth work, this repository is the public-facing content surface. `~/projects/madobe-marketing/` should be treated as the private planning workspace; reader-facing copy and conversion improvements belong here first.
